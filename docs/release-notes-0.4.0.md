# Omadrop 0.4.0

A new collection of 21 curated MilkDrop visuals, with Omadrop audio adaptations
for each scene.

- Glass, fluid surfaces, fractals, particles and light, with blended transitions.
- Continuous low, mid and high response that preserves the original artwork.
- Album artwork at startup and track changes.
- Shared scene changes and response controls across displays.
- Reproducible engine builds and safer updates that preserve the previous install.

Built with projectM and work by the credited MilkDrop artists. Preset loading can
still cause occasional short pauses. See the bundled third-party notices.
