# Omadrop package report

## Changed (product/package/)
- `build-bundle.py` — stages the relocatable bundle and emits `install.sh` /
  `uninstall.sh` plus `omadrop-0.5.0-preview.1.tar.gz`.
- `PKGBUILD` — local prepared bundle: `/usr/share/omadrop-product`,
  `/usr/share/omadrop-screensaver`, `/usr/bin/omadrop` symlink, desktop, icon,
  licenses. Depends qt6-base qt6-declarative python pipewire jq socat ghostty;
  sha256 SKIP.
- `omadrop.desktop`, `omadrop.svg` — the one launcher and icon.
- `README.md` — user-facing: features, controls, prerequisites, licensing,
  build/validation.

## Verification
- `python3 -m py_compile build-bundle.py` and `bash -n PKGBUILD` — both OK.
- Stub-GUI build: tree matches the brief, archive root is
  `omadrop-0.5.0-preview.1/`, exec bits preserved, no `/home/...` paths.
- `bash -n` on the generated installers; SVG parses.
- Throwaway-HOME install/reinstall/uninstall: single symlink, one desktop plus
  icon, prior command backed up once (no dupe), MilkDrop and settings
  untouched, prior screensaver files unclaimed, uninstall restores the command
  and removes only owned files, no temp leaks.

## Assumptions
- Layout is `share/{omadrop-product/bin,omadrop-screensaver/bin}`, then
  `share/{applications,icons,licenses}`, plus root README and installers.
- The installers are generated by `build-bundle.py`; only five files authored.
- A relative `--gui` resolves against the product dir, so the default works
  from any CWD.
- `ghostty` is in depends; Omarchy is documented in the README, not a package.
- Per-user runtime lands at `$XDG_DATA_HOME/omadrop-screensaver`, matching the
  dispatcher's default backend paths.

## Risks
- `omadrop-ui` is required; the build fails until the Qt target exists.
- Colliding files in an older screensaver install are overwritten, not backed
  up, and uninstall leaves them.
- PKGBUILD hardcodes the archive name; keep it in sync with build-bundle.py.
